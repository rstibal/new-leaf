# New Leaf

A basic default WordPress block theme built entirely from core blocks and styles — a blank-slate starting point for new projects.

**Author:** Rob Stibal ([robstibal.com](https://robstibal.com))

## Structure

- `style.css` — theme header (name, author, description)
- `theme.json` — global settings: color palette, font sizes, layout widths
- `parts/header.html` — site title, tagline, navigation
- `parts/footer.html` — site title, copyright line
- `templates/` — index, single, page, archive, search, and 404 templates

No custom PHP, no third-party blocks, no design system — just the minimum needed for a valid WordPress block theme, ready to build on.
